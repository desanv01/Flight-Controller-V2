# Engineering RC1 record

The working folder retains an earlier RC1 manufacturing archive, but a complete matching native CAD hierarchy was not recovered from it in this publication. RC1 therefore remains a documentary milestone, not a reconstructed executable source revision. Its old branding and unresolved engineering status preclude redistributing the opaque original fabrication archive as a current package.

Later EVT1 sources and packages are recovered separately and are authoritative for the current publication. Earlier MicroClasp/temporary power-path checks must not be applied to final Nano-Fit hardware. No missing RC1 CAD state was fabricated.
