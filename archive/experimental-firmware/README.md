# Experimental firmware and bench tooling

Historical STM32 HAL core/PID/filter/sensor/motor work, legacy Betaflight/iNAV target text and IMU bench tooling are retained for development coverage. These files are not a qualified build or compatibility claim for the final V2 EVT1 design. Build drivers/dependencies come from their upstream projects and retain their license headers; the copied core is a source subset. No stale branded binary is distributed.

The current reproduced firmware is the FCV2 ArduPilot target in firmware/. Original manual test success is not inferred from these scripts. Private workstation references were neutralized; consult actual hardware contracts before any runtime use.
